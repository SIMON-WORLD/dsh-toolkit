## 01｜中文路径/Windows 兼容修复包

- **痛点依据**：P016 中文路径截断（17 帖同根因 readUtf16）+ P017/P018 koffi 崩溃 + P020/P021 pwsh 假死
- **产品定义**：①整理全部 Windows 修复补丁为可 cherry-pick 的补丁集（社区已有）；②做一个 `dsh-doctor-windows` 一键诊断工具（检测 koffi 版本/路径字符/端口/沙箱状态）
- **完成路径**：
  1. W1：收集 17 帖的补丁片段，验证可复现（mock readUtf16 测试）
  2. W2：写官方讨论帖（统一根因报告 + 补丁 diff），upvote 拉拢
  3. W3：开发 dsh-doctor-windows 插件（bundle manifest + 8 项检测）
  4. W4：发布 + 打 `dsh-plugin` topic + 提交 awesome-dsh-plugin
- **验证**：中文路径工作区创建/选择成功；koffi 版本锁定后 picker 不崩
- **开源方式**：补丁集放 GitHub（Apache-2.0），文档说明"官方开放 PR 后首批合入"
