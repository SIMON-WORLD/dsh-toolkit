# DeepSeek Harness 到底怎么才能好用？我扒了官方 2764 条讨论，做了个开源工具箱

> 公众号/知乎深度长文 · 约 2000 字 · 目标：收藏 + 转发 + 引流 GitHub

---

DeepSeek Harness（DSH）开源 4 天拿下 14 万 star，口号「一切皆插件」喊得震天响。但真上手的人都有一个共同感受：**毛坯房**。

没有 @ 引用文件、纯文本模型不能看图、费用完全无感知、Windows 中文路径直接截断、环境问题要自己一个个踩坑……这些不是个别现象——我把官方 GitHub Discussions 的 **2764 条帖子**全部扒了一遍，整理出 **173 条真实痛点**，其中能靠工具/插件/文档解决的，我做成了一个开源工具箱：

**https://github.com/SIMON-WORLD/dsh-toolkit**

## 一、先说你最可能踩的 3 个坑

**坑 1：Windows 中文路径直接截断。**
工作区名字里只要带汉字（比如「需求」「开」「一」），就会被截断。这不是玄学——官方讨论区里同一个根因的帖子有 **17 条**（#107 家族），根因是 `readUtf16` 只查低字节。绕法很简单：**路径全用英文**。这 bug 官方还没修，社区已有补丁。

**坑 2：纯文本模型不能看图。**
DeepSeek 官方模型是纯文本的，你贴个报错截图它根本看不见。根因是 `inputModalities` 硬编码了 `["text"]`（#474），不是 harness 缺工具，是模型路由不认图片。解法是「视觉桥」：图片 → 外部视觉模型 → 文本描述 → 回注给文本模型。

**坑 3：费用完全无感知。**
跑完一个长任务，花了多少钱不知道。而且 8 月 17 日起 DeepSeek 改峰谷计价，Flash 输出峰值 1.32、谷值 0.66——不看账根本不知道什么时候该跑。

## 二、dsh-toolkit 做了什么

一句话：**把 173 条痛点里能被工具解决的，做成可安装、可验证、可贡献的开源包。**

| 包 | 解决什么 | 对应痛点 |
|---|---|---|
| **dsh-doctor** | 环境体检：Node 版本/koffi 锁定/端口/ASCII 路径/沙箱/hooksPath，一键检测 + 修复命令 | #649/#1719（46 评论的 dsh doctor 提议） |
| **dsh-at-file** | @ 引用工作区文件，Claude Code 同款体验 | 12 条帖子（#146 家族） |
| **dsh-cost-dashboard** | 会话 token 与费用估算，增量统计不卡顿 | #500/#318 + 峰谷计价 |
| **dsh-vision-bridge** | 图片 → VLM → 文本回注，给纯文本模型装眼睛 | #474 根因 |
| **docs/** | 中文知识库 11 篇：安装避坑/Windows 专题/插件生态/173 痛点全集/20 个拓展方向 | 官方文档不全（P150-P155） |

## 三、不是拍脑袋，是「真实环境验证过」

我做这个工具箱最在意一件事：**别给社区再添一堆装不上的东西。**

所以每个插件都走完了真实验证链路：
- **16/16 单元测试通过**（针对编译产物，不是源码 mock）
- **真实 DSH 环境安装验证**：在隔离的 DSH_HOME 里 pnpm 安装 → patch 挂载 → `dsh web` 成功启动监听 3080，插件完整加载激活
- **CI 全绿**，还加了个 `verify-format.mjs` 自动检查插件格式

过程中还实证了一个官方讨论区的坑：`@deepseek-ai/dsh-tools@0.0.1-rc.1` 的依赖 `dsh-type-meta` 根本没发布到 npm（这正是官方 #410/#2763 记录的坑），我们把它改成 `^0.1.0-rc.6` 才装上——这种「踩坑即沉淀」正是社区最需要的。

## 四、为什么值得你 star + 贡献

DSH 官方明确说了：**暂时不收外部 PR**（CONTRIBUTING.zh.md），但欢迎三件事：插件生态、中文文档、带补丁的 bug 报告。dsh-toolkit 就是这三件事的合集：

- 每个包 README 都写明「解决哪个痛点 + 帖号 + 验证标准」，照着就能贡献
- MIT 协议，随便用随便改
- 已提交 awesome-dsh-plugin 收录 PR（#1403），等合并就能被更多人找到

## 五、30 秒上手

```bash
git clone https://github.com/SIMON-WORLD/dsh-toolkit.git
cd dsh-toolkit
npm install
npm test          # 16 个用例全绿
npm run doctor    # 环境体检，一行命令
node scripts/verify-install.mjs packages/dsh-at-file web   # 真实安装验证
```

## 六、说点实话

DSH 现在是「开发者预览版」，官方自己都标注「未来将有破坏兼容性的变更」。它不适合追求开箱即用的普通用户——**它是给愿意折腾的人准备的**。但换个角度：正因为是早期，社区还有大量空白，你踩的每个坑、写的每个插件、发的每篇教程，都可能成为这个生态的一部分。

我的 173 条痛点清单和 20 个拓展方向（含完成路径）都在仓库 docs/ 里开源了。如果你也有想做的方向，欢迎来 PR——**DSH 的好用，靠的是每一个愿意动手的人。**
