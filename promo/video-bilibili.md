# B站视频脚本：3 分钟让 DeepSeek Harness 变好用（开源工具箱实测）

> 视频时长：约 3.5 分钟 · 风格：实测向、干货向 · 目标：播放 + 投币 + 评论区引流
> 画面建议：全程录屏（终端 + GitHub 页面），口播为辅

---

## 开场（0:00-0:20）

**【画面】**：DeepSeek Harness GitHub 主页（14 万 star）+ 官方讨论区截图

**【口播】**：兄弟们，DeepSeek Harness 开源四天十四万 star，口号「一切皆插件」听着很猛。但我把官方讨论区 2764 条帖子全看了一遍，发现真实情况是——毛坯房，很多基础功能都得自己装。今天给你看一个我做的开源工具箱，把最痛的几个坑全填上。

## 痛点 1：环境体检（0:20-1:10）

**【画面】**：终端跑 `npm run doctor`，输出 9 项检测

**【口播】**：先说最烦的——环境问题。Node 版本不对、端口被占用、中文路径截断、沙箱崩溃……官方讨论区这种问题几十条，就是缺一个统一体检工具，社区都在喊官方出 `dsh doctor`（那条讨论 46 个评论）。咱不等官方了，自己做一个：

**【画面】**：逐项滚动检测输出（Node 版本 ✓ / koffi ✓ / 端口 ✓ / 路径字符 ✓ / DSH_HOME ✓ / 沙箱 ✓ / hooksPath ✓）

**【口播】**：一条命令，8 项检测，每一项有问题都直接给修复命令。Windows 用户重点看「工作区路径字符」那项——中文路径截断这个 bug 官方到现在没修，17 条帖子同一个根因，最简单绕法就是路径用英文。

## 痛点 2：不能看图（1:10-2:00）

**【画面】**：演示贴图 → 模型「看不见」→ 装 vision-bridge 后能描述

**【口播】**：第二个坑，纯文本模型不能看图。你贴个报错截图，它说「我无法查看图片」。根因是模型路由把图片能力硬编码关了。解决方案是视觉桥——图片先发给外部视觉模型转成文字，再回注给 DeepSeek。我们做了个 `dsh-vision-bridge` 插件，原理讲清楚，代码全开源，还能直接接你本地的免费视觉代理。

## 痛点 3：@ 文件 + 费用无感知（2:00-2:50）

**【画面】**：装 at-file 后输入 @ 弹出文件；跑 cost-dashboard 看费用输出

**【口播】**：第三个坑，不能 @ 引用文件。Claude Code 里 @ 一下文件内容就进去了，DSH 默认没有，讨论区 12 条帖子在喊。我们做了 `dsh-at-file`。还有个很容易忽略的——费用无感知。跑完长任务花了多少钱不知道，而且 8 月 17 号起 DeepSeek 改峰谷计价了，Flash 谷价 0.66、峰价 1.32。我们的 `dsh-cost-dashboard` 帮你算账，而且用增量统计，不会像官方 TokenMeter 那样越跑越卡。

## 验证与开源（2:50-3:30）

**【画面】**：跑 `npm test` 16 个用例全绿；GitHub Actions CI 页面；awesome-dsh-plugin PR #1403 页面

**【口播】**：关键来了——这东西不是摆样子。16 个单元测试全绿，而且我在隔离环境里真实验证过：三个插件都能被 DSH 正常安装、加载、激活，`dsh web` 成功启动。CI 全绿，还提交了 awesome-dsh-plugin 的收录 PR。全部 MIT 开源，文档里连 173 条痛点清单和 20 个拓展方向都给你了，想贡献随时来。

## 结尾（3:30-3:50）

**【画面】**：仓库二维码 + GitHub 链接

**【口播】**：DSH 官方现在不收 PR，但欢迎插件、教程、带补丁的报告——这个工具箱就是这三件事的合集。链接在评论区，觉得有用点个三连，下期做「从 0 写一个 DSH 插件」实战，关注不迷路。
